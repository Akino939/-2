# 灾鉴 · 全球自然灾害风险图谱（Global Disaster Atlas）

基于 ECharts 的**全球自然灾害数据交互式可视化看板**：1990–2025 年、10 类灾种、46 国，共 11,366 起灾害事件的 8 图联动分析。

**在线预览**：<https://akino939.github.io/Global-Disaster-Encyclopedia/>

## 功能亮点

- **8 图联动筛选**：点击任意图表元素（地图点位、热力格子、旭日图扇区、柱条、玫瑰花瓣……），全页图表同步筛选，右上角可一键清除
- **右上角筛选面板**：大洲 / 灾种 / 月份下拉选项框 + 筛选标签，与点击联动互通
- **图表一览**

| 图表 | 内容 |
| --- | --- |
| 全球灾害点位分布 | 点大小 = 死亡人数，颜色 = 灾种 |
| 灾种 × 月份热力矩阵 | 1990–2025 按月汇总，色阶 = 事件数，支持数值范围滑块筛选 |
| 旭日图 | 大洲 → 国家 → 灾种下钻，右上角「还原」键复位 |
| 逐年堆叠面积图 | 各类灾害 1990–2025 事件量演变 |
| Top15 受灾国家 | 事件数 / 死亡 / 受影响人口 / 经济损失四种指标切换 |
| 国家风险散点 | 事件量 × 死亡人数双对数坐标 + 拟合线 |
| 矩形树图 / 玫瑰图 | 灾种构成占比，按钮切换两种形式 |
| 三问三答 | 「哪里 / 哪种 / 何时」读图结论 + 作者信息 |

## 技术实现

- 纯前端静态页面：HTML + CSS + 原生 JavaScript，无构建步骤
- [ECharts 5](https://echarts.apache.org/) 配置式图表（CDN 引入）
- 主页面 + iframe 图表页架构，跨窗口 `postMessage` 实现全局筛选总线
- 灾害名称中英文统一映射，配色全站一致

## 快速开始

```bash
# 本地查看：直接双击 index.html
# 或起一个静态服务器
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
├── index.html          # 主看板：布局、KPI、筛选面板、联动总线
├── data.js             # 聚合数据：热力矩阵 / 旭日树 / KPI / 中英文灾种映射
├── charts/
│   ├── map.html        # 全球点位地图
│   ├── mine.html       # 灾种×月份热力矩阵
│   ├── sunburst.html   # 旭日图（含还原键）
│   ├── area.html       # 逐年堆叠面积图
│   ├── bar.html        # Top15 受灾国家（指标切换）
│   ├── scatter.html    # 国家风险双对数散点
│   └── composition.html# 矩形树图 / 玫瑰图切换
└── README.md
```

## 数据口径

- 时间：1990–2025（2026 年 87 条不完整记录不入图）
- 季节字段已按月份修复 12.1% 矛盾值；地震重复计数已按「日期+国家+灾种」去重；Russia / Turkey 大洲标签已规范化
- 来源：EM-DAT 国际灾害数据库公开数据
